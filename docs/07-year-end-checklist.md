# Printable Year-End Checklist

One page. Print it, tape it above the desk, work top to bottom. Each item names the chapter that explains it.

**Business / year:** ______________________  **Filled out (date):** ____________

---

## Part 1 — Banking & Reconciliation · [Ch. 1](01-bank-reconciliation-december-ritual.md)

- [ ] December (and every other month's) bank statement in hand
- [ ] Every reconciliation month's balances match records to the penny
- [ ] Every stray transaction labeled: timing, fee/adjustment, or investigated
- [ ] Outstanding items list carried for January's statement
- [ ] The year's reconciliations swept and closed

## Part 2 — Categorizing · [Ch. 2](02-categorizing-a-year-of-transactions.md)

- [ ] All 12 months of transactions in one table, sorted by description
- [ ] Repeated descriptions batch-categorized; stragglers handled
- [ ] "Other" is small (≤ 5–10%) or has been split honestly
- [ ] Personal charges pulled out and noted
- [ ] Category rulings written down for reuse

## Part 3 — The Special Items

- [ ] **Mileage** ([Ch. 3](03-mileage-totals.md)): total miles written down, method note attached, odometer photos archived, next-year log plan in place
- [ ] **Contractors / 1099 facts** ([Ch. 4](04-1099-prep.md)): list of persons paid for services with amounts; W-9 on file / not on file per person; calendar reminder set for late January
- [ ] **Employees / W-2 notes** ([Ch. 5](05-w2-vs-contractor-notes.md)): five-line hire notes exist for everyone paid; any employee-shaped arrangement flagged **→ taxes: ask a pro** (before eventually hiring, next time)
- [ ] Full year's payroll closed and archived, if applicable

## Part 4 — Totals (the three answers)

- [ ] Total income for the year: $ ____________
- [ ] Total expenses, by category, one list: $ ____________
- [ ] Net: $ ____________ (income − expenses; a negative is a real answer, not a failure)
- [ ] Business miles for the year: ____________

## Part 5 — Archive & Reset · [Ch. 6](06-what-to-archive.md)

- [ ] `Business Archive/_____/` digital folder created with year's PDFs, reports, statements
- [ ] Archive copied to a **second location**
- [ ] Physical receipts photographed; originals filed/boxed to match
- [ ] Index paragraph written (what's inside, where the copies live)
- [ ] Tax-relevant questions collected in one list for a pro (**this guide answers none of them**)
- [ ] Next year's folders/log page created — future-you's December already made easier

## Sign-off

- [ ] Books can answer: income? spending by bucket? where the paperwork lives? — in under 30 seconds

**This checklist is bookkeeping mechanics, not tax advice.** Every "what do I file/claim/owe" question goes to a qualified professional or official IRS/state resources.
